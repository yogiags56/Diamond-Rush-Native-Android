# Build 22 — Interactive native gameplay preview

Changes:
- PLAY now opens an Android-native gameplay preview screen.
- Added a stone-tile cave scene, placeholder adventurer, and collectible gems.
- Touch D-pad moves the placeholder character one tile per press.
- Action collects a gem when standing on its tile.
- Pause button toggles a pause overlay.
- MENU button and Android Back return to the main menu.

Important scope:
- This is an interactive UI/visual prototype, not original Diamond Rush gameplay.
- The character, cave, and gems are placeholder canvas drawings; original assets,
  collision rules, level data, enemies, physics, and original game loop are not
  integrated yet.
- Android SDK/Gradle build was not available here, so no APK or device-run claim.
