# Android UI direction

Android-native menu and touch controls should retain Diamond Rush's identity.

## Main menu
- Android-native navigation and accessibility behavior.
- Dark carved-stone surfaces, warm gold highlights, restrained gem accents.
- Clear hierarchy: Play/Continue, Level Select, Settings, About.
- Large touch targets; original game logo/art remains the visual anchor after
  its resource is correctly decoded.

## Gameplay touch HUD
- Original world, sprites, proportions, and animation remain intact.
- Directional control cluster on the left; contextual action on the right.
- Pause remains separate from movement/action controls.
- Controls must avoid covering important gameplay content and adapt to viewport.

## Rules
- Never stretch sprites or tiles.
- Preserve original aspect ratios and animation timing.
- Adapt camera/viewport rather than crop the logical game image.
- This is a design-token baseline, not a claim that finished artwork or a
  playable prototype has been implemented.
